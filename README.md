# لعبة نجمة!

لعبة عربية خفيفة تعمل في المتصفح، ومناسبة للهواتف والحواسيب. اختر مستوى الصعوبة، والمس النجمة قبل أن تتحرك لجمع النقاط والإنجازات، ثم شارك نتيجتك.

## التشغيل والنشر

- للتجربة السريعة: افتح `najma-game.html` في متصفح حديث. بعض ميزات المتصفح، مثل التثبيت والتشغيل دون اتصال، تحتاج إلى استضافة عبر HTTPS أو `localhost`.
- هذا المستودع ينشر موقعه الحالي عبر GitHub Pages. تُضاف اللعبة في مجلد `game/` حتى تبقى الصفحة الرئيسية كما هي، ويكون رابطها `https://yousifahmed249.github.io/my-website/game/`. بعد رفع الملفات إلى فرع `main` انتظر اكتمال نشر GitHub Pages.
- لتثبيت اللعبة: على Chrome وAndroid استخدم زر «تثبيت اللعبة» عندما يظهر. على iPhone/iPad افتح قائمة المشاركة في Safari ثم اختر «إضافة إلى الشاشة الرئيسية». بعد تحميلها لأول مرة عبر الإنترنت، يمكن فتحها دون اتصال.
- تشمل اللعبة مؤثرات صوتية قابلة للكتم، حركة متزايدة السرعة، وثلاثة إنجازات محفوظة على الجهاز. يمكن تعطيل الصوت من زر الصوت.
- يلزم HTTPS لتعمل المشاركة الأصلية ونسخ الرابط على جميع المتصفحات. على الأجهزة غير الداعمة للمشاركة، تعرض اللعبة طريقة نسخ الرابط يدويًا.

لا تحتاج اللعبة إلى خادم أو مكتبات خارجية أو حسابات. تُحفظ أفضل نتيجة على جهاز اللاعب فقط، ولا تُرسل بيانات إلى أي جهة.

## الظهور في محركات البحث

- بعد النشر، أضف موقع `https://yousifahmed249.github.io/my-website/` إلى Google Search Console، ثم أرسل خريطة الموقع `https://yousifahmed249.github.io/my-website/sitemap.xml`.
- استخدم فحص عنوان URL في Search Console لطلب فهرسة `https://yousifahmed249.github.io/my-website/game/najma-game.html`.
- الفهرسة والظهور قد يستغرقان وقتًا ولا يمكن ضمان ترتيب أو ظهور محدد. تأكد أن صفحة اللعبة متاحة للعامة عبر HTTPS.
- استخدم اسمًا واضحًا مثل «لعبة نجمة» عند مشاركة الرابط؛ لا تكرر الكلمات المفتاحية بشكل مصطنع.

انتشار اللعبة غير مضمون؛ زر المشاركة يسهّل مشاركة النتيجة والرابط، ولا يرسل أي شيء تلقائيًا.
